# Validation Brief

> Module 2 · Validation. Frame the riskiest assumption, then build to test it. **This locks your scenario, no switching after M2.**

## Scenario

Scenario 04 · The Dashboard Nobody Reads

## Riskiest assumption

_The one belief that, if false, sinks the idea._

The data being displayed indicates what happened but never explains the next course of action to fix the issues so users end up finding it not useful.

## Hypothesis

> We believe **a first screen that has a landing dashboard with all the apps and tools used by banking clients, in plain-language,  with the ability to filter , and shows the high level friction points with the recommended action/s** will cause **users to find the dashboard useful and use the data shown instead of using other unverified data sources or not using it all** for **banking employees who make critical decisions on the direction of apps/tools used by banking customers**. We'll know we're right when **bounce rate drops, there is an increase in the use of the dashboard, including drilling down into detail, friction points and recommended actions are explored by the team as part of the iterations done to the tools and apps**.

## Risk type

- [ ] Value (do they want it?)
- [x] Usability (can they use it?)
- [ ] Feasibility (can we build it?)
- [ ] Viability (should we?)

## Kill switch

_The result that would make you stop or pivot._

If users are still struggling to read the landing dashboard data or even filter to an app/tool, the core issue outlined itself may be wrong, pivot.

## The three ingredients

- **Real data (domain metrics):**
  - 74%, Users who export to a spreadsheet to actually analyse.
  - 12, Charts on the default landing view.
  - 6 clicks, To reach the most-requested metric.
  - 60%, Bounce rate: sessions under 15s with no interaction.
- **User voice (verbatim quotes):**
  - "It tells me *what* happened but never *what to do about it*. I still export to a spreadsheet to think.", Product lead
  - "The number I need is in there, but it takes six clicks and three filters to find it.", Growth analyst
  - "I open it, see twelve charts, and have no idea which one I'm supposed to act on. So I close it.", Marketing manager
- **Hypothesis (above):** ✓
