## What the evidence says

_What real usage showed: numbers if your tool has analytics, counted behaviour if it does not. Put the signal that matters on screen._

- **Primary signal:** Users can navigate the site however there's an opportunity to fix the bugs and find ways to ensure the user always comes back
- **What moved:** The user experience - it's clean and easy to navigate and follow
The filters enable users to be able to find the data
- **What didn't:** Buttons not working; illustrative listed on the site which caused confusion
friction: insights/signals are hidden all the way at the bottom, would be good to navigate to the top

The Engagement & Task completion hover over on the graph seems to stay static on the lower-left corner of the chart. Might be good to have it move with the hover over.  The user needs to move his/her eyes to read the legend while moving the mouse

_Observed behaviour: reach 4 of 6; core action 4; stall point Friction points; explained away What illustrative is meant to do ; buttons not working as intended; own first run 2 pauses after login - exploring the friction points and understanding what illustrative means._
